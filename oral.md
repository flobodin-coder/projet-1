# Oral 

### objectif 

Tenir 10 min a l'oral en présentant le projet 

### ce qu'on doit montrer:
- Nom (1)
- But (2)
- Rendu (3)
- Difficultés (5)
- Apport (6)
- Comment vous avez fait: (4)

    - Manière dont vous avez codé
    - Presenter un bout code
